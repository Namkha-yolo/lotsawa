How to Enable the Keyboard

  1. Open Settings on your iPhone
  2. Go to General → Keyboard → Keyboards
  3. Tap Add New Keyboard...
  4. Select Lotsawa
  5. Switch keyboards using the 🌐 globe key

Usage Tips

  • Phonetic mode: Type "tashi delek" → བཀྲ་ཤིས་བདེ་ལེགས།
  • Wylie mode: Type "bkra shis" → བཀྲ་ཤིས་
  • Tap the mode indicator to switch between Phonetic and Wylie
